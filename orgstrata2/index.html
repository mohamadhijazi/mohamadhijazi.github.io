About the Architect & Engineering Vision

Created by Mohammad Hijazi, this platform demonstrates the power of zero-dependency, local-first web architecture.

Zero-Framework Vanilla JS

Built strictly with native ES6 JavaScript, HTML5, and modular CSS3. No NPM, no Webpack, no frameworks — runs by opening index.html directly.

Standard Web API

Local-First Data Sovereignty

All workspace data persists exclusively in your browser's LocalStorage. Full workspace CRUD: create, clone, delete workspaces, pages, and components.

Privacy Sovereign

Universal Component Studio

Every component has a Settings drawer and paired Data Table editor. Import/export via CSV or JSON. Live chart updates on data change.

Real-Time Driven

How the Workspace Works

From personal 5-year planning to enterprise value chains — manage everything through unified component pages.

01

Select Workspace

Switch between Personal Twin ("Family of 4") and Enterprise Twin ("Company of 200") or create/clone your own.

02

Manage Pages

Add, rename, or delete pages in the left sidebar. Each page holds an independent component grid.

03

Add Components

Choose from 11 component types: Charts, Calendar, Map, BPMN, DataTable, Kanban, Gantt, Risk Matrix, Capabilities, Maturity, 3D Floor Plan.

04

Studio & Data I/O

Click the ⚙ gear on any component to open Component Studio: edit data, import/export CSV or JSON, and configure layout settings.
