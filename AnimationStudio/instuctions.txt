Context & Objective
Build a browser-based 2D Animation Studio using pure Vanilla JavaScript, HTML, and CSS. The app allows users to create up to 3-minute animations, draw custom SVG characters, manage a keyframe timeline, upload MP3 audio, and export the final movie.
Technical Constraints
Core: Vanilla JS (ES6 modules), HTML5 Canvas API for rendering, Web Audio API for sound synchronization.
No Heavy Frameworks: Do not use React, Vue, or Angular. Keep DOM manipulation native.
Storage Engine: Use IndexedDB (via native API or localforage) for state management to bypass standard localStorage size limits.
Media Export: Use the MediaRecorder API to capture the Canvas stream and Web Audio destination node into a downloadable .webm or .mp4 file.
Import/Export: Support downloading and uploading the entire project state as a .json file.
UI/UX Layout Rules
Create a dark-mode, professional studio aesthetic with three main panels:
Left Panel (Library & Tools): Asset Library showing saved SVGs, MP3s, and Backgrounds. Include an "SVG Builder" overlay for drawing basic vector shapes and saving them as inline  strings.
Center Panel (Stage): The HTML5 Canvas Stage (16:9 ratio, scaling to fit the window). Allow users to drag, scale, and rotate actors directly on the canvas.
Bottom Panel (Timeline): The Keyframe Timeline with multi-track support (Backgrounds, Characters, Audio). Include Play, Pause, and Stop buttons, and a visual playhead.

Implementation Phases
Do not build everything at once. Build this systematically and wait for my approval before moving to the next phase.
Phase 1: Scaffold the HTML/CSS layout (Stage, Timeline, Asset Library) and set up IndexedDB storage, ensuring the seed data populates on first load.
Phase 2: Build the HTML5 Canvas rendering engine. Parse the seeded  strings into image objects and draw them at their exact x, y coordinates. Add canvas drag-and-drop logic.
Phase 3: Implement the Keyframe Timeline interpolation logic. Create the playhead behavior that updates Canvas positions based on the current frame.
Phase 4: Add the SVG Character Builder UI module and the file uploader for MP3 tracks.
Phase 5: Integrate the Web Audio API for synchronized playback and implement the MediaRecorder video export logic
