L1 – Infrastructure Layer (SAFe Architecture View)

SAFe Roles & Architecture
  • Enterprise Architect: cloud strategy, regions, landing zones, infra runway.
  • System Architect: Kubernetes patterns, monitoring, logging, resilience.
  • Architectural Runway: infra-as-code, observability, DR ready for features.
Principles
  • P1 Economic View: cost-optimized infra, autoscaling, right-sizing.
  • P2 Systems Thinking: latency, throughput, reliability across stack.
  • P6 Flow: automated provisioning, no manual infra gates.
Security, Governance & Quality
  • Security: Zero Trust, encryption, secrets management, SIEM/SOC.
  • Governance: approved infra patterns, architecture standards, audit trails.
  • Quality: SLOs, DR tests, chaos engineering, infra tests (Terraform, Helm).
L1 = Reliable, observable, secure foundation for all AI and agentic services.

L2 – AI Platform & Integration Layer

SAFe Roles & Architecture
  • System Architect: AI gateway, LLM integration, MCP contracts, prompt infra.
  • Solution Architect: cross-ART interoperability, multi-LLM strategy.
  • Runway: reusable AI platform capabilities for all ARTs and agents.
Principles
  • P3 Variability & Options: multi-LLM, pluggable gateways, configurable prompts.
  • P4 Incremental Build: start with core flows, extend tools and MCP over PIs.
  • P7 Cadence & Sync: platform roadmap aligned with PI cadence.
Security, Governance & Quality
  • Security: IAM, RBAC/ABAC for models, tools, prompts.
  • Governance: model governance, prompt governance, usage policies.
  • Quality: latency, throughput, safety filters, integration tests.
L2 = Governed AI platform enabling safe, composable agent and app integration.

L3 – Enterprise Information Layer

SAFe Roles & Architecture
  • Enterprise Architect: data strategy, domains, canonical models.
  • System Architect: API contracts, event schemas, data access patterns.
  • Organize Around Value: data domains aligned to value streams.
Principles
  • P2 Systems Thinking: data as product, end-to-end lineage.
  • P10 Organize Around Value: information mapped to operational flows.
Security, Governance & Quality
  • Security: DLP, access controls on APIs, DBs, lakes.
  • Governance: data governance, privacy, retention, regulatory compliance.
  • Quality: data quality (accuracy, freshness), lineage, NFRs for performance.
L3 = Trusted, governed enterprise information feeding knowledge and agents.

L4 – Knowledge & Intelligence Layer

SAFe Roles & Architecture
  • Solution/System Architect: unified index, RAG patterns, KG & ontology.
  • Runway: shared search and knowledge services for all ARTs.
Principles
  • P3 Variability: multiple retrieval strategies (BM25, vectors, KG).
  • P5 Objective Milestones: validate via working RAG use cases.
Security, Governance & Quality
  • Security: access-aware search, RBAC/ABAC in index.
  • Governance: policies for indexing scope, PII handling, retention.
  • Quality: relevance metrics, feedback loops, KG consistency checks.
L4 = Unified, governed knowledge fabric powering precise, context-aware AI.

L5 – Agentic AI Services Layer

SAFe Roles & Architecture
  • System Architect: agent orchestration, tool contracts, HITL integration.
  • Solution Architect: multi-agent flows across systems and ARTs.
Principles
  • P8 Intrinsic Motivation: empower teams to build agents within guardrails.
  • P9 Decentralized Decisions: local agent design, centralized safety standards.
Security, Governance & Quality
  • Security: audit logs for agent actions, tool calls, HITL approvals.
  • Governance: Responsible AI, ethics, model governance for agent behavior.
  • Quality: scenario tests, failure modes, escalation paths, HITL gates.
L5 = Governed, testable agent ecosystem with human oversight for high-risk decisions.

L6 – Users & Experience Layer

SAFe Roles & Architecture
  • Product Management + Architects: UX patterns, personas, value hypotheses.
  • System Architect: safe integration of UX with agents and knowledge.
Principles
  • P4 Incremental Build: ship small UX slices, learn from usage.
  • P5 Objective Milestones: measure UX via working features.
Security, Governance & Quality
  • Security: SSO, federation, RBAC/ABAC per persona.
  • Governance: privacy controls in UI, consent, data visibility.
  • Quality: usability, accessibility, feedback loops, telemetry.
L6 = Secure, role-aware experiences that expose AI safely and usefully.

L7 – Business Value & Outcomes Layer

SAFe Roles & Architecture
  • Enterprise Architect + Business Owners: tie architecture to ROI, risk, productivity.
  • Lean Portfolio Management: epics and guardrails aligned to outcomes.
Principles
  • P1 Economic View: architecture choices justified by ROI and cost of delay.
  • P6 Flow: measure impact on lead time, throughput, incident reduction.
Security, Governance & Quality
  • Security & Governance: compliance management, audit & assurance, risk management.
  • Quality: outcome metrics, user satisfaction, continuous improvement.
L7 = Portfolio-level view where architecture is judged by business outcomes.

  • Governance: AI, data, model, architecture, compliance embedded as enabler epics/features.
  • Security: treated as NFRs at every layer; reusable platform capabilities.
  • Policies & Standards: SAFe guardrails visible in backlogs and PI planning.
Observability & Cost
  • Observability: telemetry, tracing, metrics from L1–L7.
  • Cost Optimization: economic view applied to infra, models, agents, features.
SAFe Architecture Cheat Sheet (Condensed)
  • Agile Architecture: intentional + emergent, continuous evolution, DevOps-enabled.
  • Roles: Enterprise (strategy), Solution (large solution), System (ART/system).
  • Runway: technical capabilities ready before features.
  • Principles: economic view, systems thinking, variability, incremental build, objective milestones, flow, cadence, motivation, decentralized decisions, organize around value.
  • DevOps (CALMR): culture, automation, lean flow, measurement, recovery.
